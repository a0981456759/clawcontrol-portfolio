# Capturing real portfolio screenshots

1. Run `python3 -m http.server 8080` in the repository.
2. Open `http://localhost:8080` in a browser and confirm the header says **OFFLINE / SYNTHETIC DATA ONLY**.
3. Capture the **Referral queue** and **Case workflow** with only the built-in `DEMO-` patient fixtures.
4. Select Cardiology, click **Find mock specialist**, and capture the specialist selection state.
5. If adding screenshots to `docs/screenshots/`, ensure no browser personal profile, workspace notification, real patient information, passwords, keys, URLs with query tokens, or collaborator content appears.

Only include screenshots of the actually running local demo. Do not represent conceptual AI-generated imagery as an application screenshot. This documentation intentionally contains no fabricated screenshot asset.
